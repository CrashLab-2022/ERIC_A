(Erica Robot Intelligence Car - Automatic delivery)

TL;DR: ERIC-A is an indoor autonomous robot that receives delivery orders from the web, navigates to destinations, detects people in its path, and returns to its station.

ERIC-A combines a ROS-based mobile robot stack, indoor localization, path planning, YOLO vision, voice guidance, and a web service for delivery request management. A user submits an order, an administrator selects deliveries, and the robot travels to the selected destination while announcing its presence around people.

System Highlights

Autonomous navigation

ROS launch files for SLAM, localization, move_base, and robot bringup.

Human-aware delivery

YOLO-based vision support for detecting people and triggering voice alerts.

Order-to-robot flow

Web ordering and admin controls connect delivery requests to robot dispatch.

Hardware integration

Motor, lidar, IMU, servo, and robot description packages share one workspace.

Architecture

Web Interface

The web application connects delivery requests to robot operation. Users can place and track orders, while administrators review requests and control each delivery from pickup through completion.

User experience

  • Sign up, sign in, and submit delivery requests.
  • Track the current status and review delivery details.
  • Open the robot lid when an in-person delivery arrives.

Administrator controls

  • Accept or reject incoming delivery requests.
  • Dispatch the robot and monitor delivery progress.
  • Open or close the robot lid when handling packages.
